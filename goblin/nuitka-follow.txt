# Nuitka import control for the goblin binary build.
#
# This file is read by the build-binary task in Taskfile.yml and appended to
# the Nuitka command line. It documents the dependency audit and keeps the
# standalone binary from pulling in packages that are installed in the
# workspace but are not used by goblin at runtime.
#
# Audit summary (source-only imports in goblin/ and goblin_common/):
#   Direct third-party imports: click, filelock, goblin_common, jinja2,
#     json_repair, jsonschema, notifications_relay, openhands, pydantic,
#     turso (pyturso), yaml (pyyaml).
#   litellm is required at runtime by openhands-sdk but is not imported
#     directly by goblin, so it is no longer declared as a direct dependency.
#
# Heavy optional distributions that are present in the lock file but are not
# imported by goblin or its runtime dependencies are excluded below.
